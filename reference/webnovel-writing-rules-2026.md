## 二、开篇：黄金三章（决定 80% 留存）

| 位置 | 硬指标 |
|---|---|
| **前 300 字** | 必须出现核心冲突（禁大段环境/背景铺垫） |
| **500 字内** | 明确主角目标与阻碍 |
| **1000 字内** | 触发首个爽点 |
| **3 章内** | 主角必须出场，个性必须凸显 |
| **5 章内** | 最好有主线大冲突，否则必须有记忆点桥段 |

**三章分工**：第 1 章抛反转 → 第 2 章情绪高潮（反击/觉醒）→ 第 3 章补设定 + 悬念升级。

**硬禁令**：大段世界观科普、开篇信息轰炸——**世界观必须由人物行动带出**。

## 三、节奏：3-5-10 法则（核心命脉）

```
每 3-5 章   小爽点   小打脸 / 小收获 / 小危机化解
每 10 章    中型反转  反派算计落空 / 身份线索曝光 / 金手指升级
每 20-30 章 大型高潮  主线阶段突破 / 势力洗牌 / 重大恩怨了结
```

- **爽点间隔 ≤ 4 万字**；受挫后 **3 万字内必爽**（爽文可加挫折，但绝不虐主）
- **每 60 章换一次地图**：新地图 = 新人物 = 新冲突 = 新爽点
- **三重爽点共振**：同一章内同时实现「逆袭打脸 + 资源收获 + 关系突破」
- **单元剧结构**：把百万字拆成若干 10 万字小战役，避免"永远在打怪"
- **铺垫 → 过程 → 余波** 三步法：事件结束要有后续影响（情绪变化/关系改变/新矛盾）
- **长线悬念（俄罗斯套娃）**：表层（当下危机）→ 中层（身世/金手指来源）→ 终极（世界真相）
- **伏笔浅埋快收**：前期道具/对话**百章内闭环**，避免"挖坑不填"恶感

**两条节奏红线**：全程流水账无冲突 ✗；全程高强度打斗无松弛 ✗。

## 四、详略分配（直接回答"哪些详写、哪些一笔带过"）

| 必须**放慢写细** | 必须**一笔带过** |
|---|---|
| 动作交锋的每一拍（招式因果、方位、身体反馈） | 赶路、吃饭、洗漱、换装等过场 |
| 关键对白（含潜台词、被打断处） | 已交代过的设定与信息（**重复即注水**） |
| 转折点与反转揭晓 | 配角无关紧要的加戏 |
| 爽点爆发与情感高光 | 主角内心反复纠结（**必须落地为行动**） |
| 首次出现的核心道具/机制（由动作带出） | 世界观科普、旁白式说明 |

**每章自检四问**（任一为否 → 删掉重写）：
1. 提供了什么**新信息**？
2. 推动了什么**剧情**？
3. 人物关系或主角实力**有无变化**？
4. 读者情绪**有无被有效撬动**？

## 五、人设（避免扁平）

- **先画面，再抓 2-3 个特征**，不堆五官 —— 读者记住的是"画面感"
- **一人一个专属小动作**（紧张转戒指 / 愤怒扯领带 / 撒谎摸鼻子）—— 比一百个形容词管用
- **外在一套、内在一套**，用反差立住厚度（人前游刃有余，人后偷偷 emo）
- **故事驱动力 = 欲望受阻**：每章问一个"现在就要答案"的欲望问题
- **不写情绪，写动作的痕迹**

---

## 六、章末钩子（打开率 +50%）

四种高转化钩子：
1. **对话中断**：关键信息说到一半被打断
2. **动作中断**：主角刚要出手，被系统警告/外部事件打断
3. **信息不对称**：读者知道主角不知道的陷阱（替主角着急）
4. **金句钩子**：能截图发朋友圈的那种

**硬禁令**："欲知后事如何，且听下回分解"——2026 年等于告诉读者"你可以不看了"。

## 七、毒点清单（踩一个掉一批读者）

| 毒点 | 表现 | 破解 |
|---|---|---|
| **逻辑崩塌** | 反派死于话多；一句话能解的误会拖百章；全员智商掉线 | 把每个角色当"人"问：他的真实动机是什么？ |
| **三观炸裂** | 挖肾挖眼灭门一句道歉就团圆；用"苦衷"洗白恶行 | 反派可坏得有魅力，但**作者不能模糊善恶边界** |
| **恶意注水** | 一章半章回顾；一个打脸水三章；配角疯狂加戏 | 追求信息密度与情绪进度 |
| **人设崩塌** | 主角降智/圣母白莲花；配角纯工具人 | 配角要有独立人格 |
| **强行喂屎** | 在爽文里塞憋屈剧情 | 受挫必须在 3 万字内找回场子 |
| **战力崩坏** | 前期费劲打死的敌人，后期路人都能碾压 | 战力体系前后一致 |
| **压战力补丁** | "我能无限加点"→第 50 章"骗你的，有上限" | 开局别给满，给也要给得诚实 |
| **剧情猛踩刹车** | 一卷 60 章，下一卷 360 章 | 卷长均衡 |
| **套路固化** | 看了开头猜到结尾 | 反套路 / 跨界融合 |
| **AI 腔露马脚** | 用 AI 不审稿，句式工整、无个人痕迹 | 见第八条 |

## 八、⚠️ AI 红线（必须知道，涉及项目风险）

> **番茄平台：纯 AI 生成作品永久封禁；AI 辅助创作需提交人工底稿，原创度必须 100%。**

**对本项目的含义（重要）**：
- 本微调模型是**写作辅助工具**，产出的是**初稿**，必须**经我逐句改写、注入个人风格与细节**才算成稿
- 不要把模型输出直接发布 —— 一是平台红线，二是本模型本就学不到"判断层艺术"（何处留白、何细节值得写）
- 正确分工：**我写大纲（判断）+ 模型出初稿（落笔）+ 我改写定稿（注入灵魂）**
