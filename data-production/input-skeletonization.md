# input 骨架化：把"流水账大纲"改成"剧情骨架"

> 病灶：现有 `input` 几乎就是 `output` 的压缩版（连"菜刀/短刀/三口棺材/劳保服/黄铜锥"都给了）。
> 后果：模型只需**换个说法复述**就能交差 → 学不会"自己长细节"，输出零环境描写。
> 解法：`input` 只给**人物动机 + 关键动作 + 结果/转折**，把**具体物件名与感官细节留给 output 去创造**。

---

## 一、逐句对比（SEG-0015-01｜第15章 红舞鞋）

### ❌ 现版 input（细到可以照抄）
> 张元清听到隔壁有动静。他把菜刀换成短刀、木棍换成长枪，出屋到窗下偷看。屋里有三口棺材、两具穿劳保服的干尸，以及一柄没生锈的黄铜锥。他想起三道山娘娘五指合拢却手心空着的手。中间棺材盖滑开，爬出一具僵尸。张元清判断这是僵尸，想到镇尸符，决定退回主殿。这时趴肩鬼压上他的肩膀，十五分钟到了。

问题：**所有名词都写死了**。模型照抄"三口棺材""劳保服""黄铜锥"即可，无需任何创造。

### ✅ 骨架版 input（只给推进与因果）
> 张元清听见隔壁有异响，换上称手武器，摸到窗下窥探。屋内陈设透着反常，另有一件与旧线索隐约呼应的器物，格外扎眼。中间那口棺材忽然翻开，凶物现形，他判断出其来历，决定先撤。就在转身的刹那，早先的算计应验了。

问题解决：**物件、光影、尸体的样子、联想如何落地，全都要模型自己写**。

### 对照 output（原文里模型本该"长出来"的东西）
> 月光如霜，四周寂静 / 糊窗的纸早已破烂，从格子窗的某个破口望进去 / 清冷如霜的月光被屋顶破洞压缩成一道道光束 / 黑色的油漆斑驳，棺盖落满灰尘 / 所有的武器都生锈了，唯独它黄澄澄的，不见铜锈 / 他脑海里没来由的浮现一个画面，三道山娘娘的一只手，五指合拢做持握状。但手心空空如也。

这些**没有一个字**出现在骨架版 input 里——这才是"扩写"。

## 二、抽象化规则（把 input 降一级）

| 保留（写进骨架） | 抽象掉（留给模型生成） |
|---|---|
| 谁、在哪、要干什么 | 具体道具名（菜刀→"称手武器"） |
| 关键动作与因果链 | 环境细节（月光/灰尘/光束） |
| 结果与转折（谁死、谁赢、什么翻盘） | 凶物的外观（浮肿/尖牙/尸气） |
| 与旧线索的**关系**（"与旧线索呼应"） | 具体是哪条旧线索、怎么联想 |
| 时间压力/倒计时 | 计时如何被感知 |

**红线**：抽象化**不得改变剧情**——谁做了什么、结果如何，必须一致。只是把"名词和画面"抽掉。

---

## 三、收益预判

| 项 | 现版 input | 骨架版 input |
|---|---|---|
| 模型可照抄的比例 | 高（≈70% 名词直接搬） | 低（≈20%，只剩人名与动作） |
| 是否必须自造细节 | 否 | **是** |
| 预期效果 | "大纲改写器" | 逼近"扩写器" |
| 风险 | —— | 若模型能力不足，可能写偏；需配合 v3 硬约束【细节自生】 |

> **配套**：骨架化必须与 `dataset_lingjing_v3.jsonl`（未随仓库发布）的【逐条落实】约束同用，
> 否则模型可能"自由发挥"过头、丢掉伏笔。

---

## 四、执行建议

1. **先小样试点**：抽 30 条做骨架化 → 重训 → 对比"细节密度"（可用脚本量化：环境名词数、感官词数）。
2. 若细节密度显著上升 → 全量 240 条骨架化。
3. 与 v3 硬约束指令、v2 超参、通用语料 replay 同批重训。

现有脚本就能批量提取"output 中未出现在 input 里的名词/描写词"，量化每条的可照抄率，
据此筛出"最需要骨架化"的条目优先处理——这件事随时可做。
