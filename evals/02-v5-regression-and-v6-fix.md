# v3 → v5 评测结论 · 同口径八探针实测

> 评测时间：2026-09-12
> 两个模型用的是**同一套十个探针、同一套生成参数**（temp 0.7 / top_p 0.9 / rep 1.1 / ngram 4 + stop_strings），
> C1 探针走的是**真实生成管线**（含专名锚点与硬约束），不是另拼的 prompt。
> 所以两张成绩单可以直接对比。

---

## 一、总判断：**v5 是一次退步，不是进步**

| | v3（0.56 轮，灵境+大奉） | v5（1 轮，五书） |
|---|---|---|
| 说人话 | ✅ 通过 | ✅ 通过 |
| 卖报笔法（卖报＝网文作者"卖报小郎君"的简称） | ✅ 通过 | ✅ 通过 |
| 大纲式（C1） | ❌ 未落地，但用上了我的设定词 | ❌ **更差**：连设定词都没用上，还严重人名漂移 |
| 感情戏·糖（G1） | 一般（结尾有留白） | ❌ 更差（直陈情绪 + 英文词泄漏） |
| 感情戏·刀（G2） | ✅ **明显更好**（克制、留白、刀感十足） | ❌ 严重失败（完全没写出诀别） |
| 人名一致性 | 差（2~3 个变体） | **更差**（多到 6 个变体） |

**v5 训练量是 v3 的近 2.5 倍（367 步 vs 150 步），结果反而更差。** 这个反直觉的结果有硬证据支撑。

---

## 二、硬证据：模型在"背源书人物"

我把评测输出里出现的可疑人名，逐个回源书查了出现次数：

| 输出里的人名 | 出现在 | 次数 |
|---|---|---|
| **李东泽** | 《灵境行者》 | **717 次** |
| **王泰** | 《灵境行者》 | **254 次** |
| **小圆** | 《灵境行者》 | **929 次** |
| 李永辉 / 林沐婉 / 林慕婉 | 五本书全部 | **0 次**（模型自己编的） |

也就是说：C1 探针（我的第二卷第 3 章大纲）里，模型把**《灵境行者》的李东泽当成了主角**在写；
G2 探针里它把**王泰**搬了过来。同时这些名字还会自己漂移（李东泽/李东择、林沐婉/林沐琬/林慕婉）。

顺带纠正一个我自己的错判：我一开始怀疑"小圆"是新加那本短篇串进来的，
查了才发现它是《灵境行者》的角色（929 次）。**先查数据再下结论，这次又救了我一次。**

## 三、根因：模型从未学过"使用专名锚点"

推理端的 prompt 里有一段（真实人名发布时以占位符代替）:
```
【本作专名·只能用这些名字】主角、示例角色1、示例角色12、同协、星澜、示例设定……
```
但**训练数据里从来不存在这一段**。

LoRA 微调学到的是"这个格式的 prompt 该产出什么"。没见过的东西，模型就当它不存在，
于是退回它最强的先验：**卖报原著的人物表**。而 v5 训得更充分，这个先验反而更牢固，
所以退步了。

这也解释了为什么 v3 反而"看起来好一点"：v3 欠训练，先验没那么强，还会去编通用名字；
v5 学得更透，就更倾向于直接搬源书的人。

**结论**：不是数据越多越好，也不是训练越久越好。**prompt 结构必须与推理端逐字对齐。**

## 四、已落地的修正 → v6（已开跑）

1. **训练样本全部注入同格式专名块**
   续写式与大纲式 3020 条样本，input 开头都带上
   `【本作专名·只能用这些名字】` + **该源书自己的名字表**
   （灵境样本配灵境人物、大奉样本配大奉人物）。
   模型因此学到的是**机制**（"锚点里列的就是要用的名字"），而不是某一份具体名单。

2. **专名表由原文频次抽取，且逐个人工核验**
   新增 `scripts/build_glossary.py`。我原本凭印象往表里加了"谢怜、张灵玉、郭小曼、陈潇"，
   回原文一查**全部 0 次**，已删除。最终表只保留能查到的高频真名。

3. **补上"硬约束"段**，让训练与推理结构一致（推理端放人物卡，训练端放该场景真实出现的人物名）。

**v6 进度**：367 步，约 23s/步，预计 **当天** 完成，由看门狗托管（崩了自动续训）。

## 五、感情戏人工判读（自动分查不出，只能我读）

这本短篇的价值在"恋爱与殉情"，我因此逐字读了 G1/G2 两段。

### G2 感情戏·刀 · **v3 这段是整晚最好的一次产出**

> "我给你做一顿饭吧。"她笑眯眯的说道。
> 陈牧顿时明白了过来，他心里一酸："好。"
> **他知道，这是她的告别。**
> 他默默的看着女人熟练的切菜、洗米、下锅……"你多吃点。"她柔声说。
> **男人默默的吃着饭，他没说话，也没看女人的脸庞。**
> ……她知道，再过两个小时，她就要离开这个世界，所以她把能带走的东西都带上了。
> **床铺上留下了一个空荡荡的被窝，没有主人。**
> 客厅里传来电视的声音，那是陈牧独自一个人看电视的声音。
> ……"我有一个朋友得了重病，可能撑不了多久了……"

**这正是我要的东西**：不喊痛、不煽情，情绪全部由动作承载（"没说话，也没看女人的脸庞"），
"空荡荡的被窝，没有主人"一句就把刀递到了读者手里，最后用"我有一个朋友"把话咽回去。
糖刀结合的留白处理，方向是对的。

### 而 v5 的同一题：

> "你做的饭可真好吃，比外面的餐馆还美味。"
> 王泰看着她笑靥如花的脸庞，心里暖洋洋的。
> ……两人坐在餐桌边，有说有笑，气氛很愉快。
> ……我明天还要上学，要早点睡，别熬夜了。

**完全没写成诀别**：气氛是"有说有笑"，结尾还冒出"我明天还要上学"，
和"她时间不多了"这个前提出了硬冲突。加上王泰/林沐婉/林沐琬/林慕婉/林暮婉六个名字变体，这篇是不合格的。

### G1 感情戏·糖

v3 结尾：`许青璇睫毛微颤，轻轻回吻了他的手心。然后，沉沉入梦。`
v5 结尾：`这个家的温馨，让他很踏实……是他一直以来的梦想。`

v3 是留白，v5 是把结论直接说出来（违反番茄档——番茄平台的风格档位——「情绪外化为动作，禁直陈」）。
另外 v5 那段里混进了一个英文词 **"Ice，你别傻了"**，属于明显瑕疵。

**感情戏结论**：v3 已具备"克制叙述"的雏形，但都被**人名漂移**和**源书人物串台**拖累。
这也正是 v6 要修的东西。

## 六、该记下的教训

1. **训练 prompt 必须与推理 prompt 逐字对齐**。少一段、多一段，模型就可能整段无视。
2. **训得越久不等于越好**：数据里若存在更强的强先验，训得充分反而放大它。
3. **自动分不能信**：本次十个探针里，自动判定"通过"的有 7 条，但人工读下来只有 3 条站得住。
4. **不要凭印象补数据**：我加的四个"人名"在原文里 0 次。零虚构原则要落到每一次改动上。
5. **同一个夜晚我犯了两次同类错误**：一次是把短篇当成残卷，一次是凭印象加人名。都要靠回查原文兜住。
