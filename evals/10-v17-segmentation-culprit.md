# v17 归因实验结论：**分段训练就是风格退化的元凶**（卖报＝网文作者"卖报小郎君"的简称）

> 实验设计：数据、学习率（5e-5）、调度器（cosine）、rank、cutoff **全部与 v15 完全一致**，
> 唯一变量是把「单段跑」换成「分段跑（每 80 步重启进程）」。目标 292 步，跑满，exit 0。

---

## 一、判定结果：证据干净

| 指标 | 卖报区间(P10~P90) | **v15（单段）** | **v17（分段）** | v16（分段+新数据） |
|---|---|---|---|---|
| 对白占比 | 13.2~35.6 | 22.4 内 | **11.5 偏低** | 10.1 偏低 |
| 平均句长 | 25.1~32.8 | 25.1 内 | **22.3 偏低** | 22.9 偏低 |
| 句长波动 | 14.9~20.8 | 15.4 内 | **12.0 偏低** | 12.6 偏低 |
| 平均段长 | 30.7~36.7 | 27.7 偏低 | 25.1 偏低 | 25.4 偏低 |
| 段长波动 | 14.5~20.2 | 16.0 内 | **11.1 偏低** | 12.9 偏低 |
| 直陈情绪 | 0.19~1.3 | **0.9 内** | **1.39 偏高** | 1.64 偏高 |
| 比喻词 | 0.37~1.49 | 0.8 内 | **1.74 偏高** | 0.65 内 |
| 套话连接词 | 0~0.75 | 1.1 偏高 | 1.62 偏高 | 1.2 偏高 |
| 升华句 | 0~0.37 | 0.1 内 | **0.93 偏高** | 0.33 内 |
| **偏离项数** | | **2** | **9** | **7** |

**数据相同，只改训练方式，偏离项从 2 涨到 9。→ 分段训练有害，结论成立。**

## 二、机制

分段时必须把检查点里的 `optimizer.pt` / `scheduler.pt` 改名（绕开 torch<2.6 的 CVE 限制），
所以**每段的优化器动量与 LR 曲线都从头开始**：

- 每段开头都是最高学习率（5e-5），80 步内把 loss 猛压下去
- v16 的 `train_loss = 0.68`（v15 是 2.83）就是过度下降的表现
- 模型被压向训练分布 → 句子变短、对白变少、比喻与情绪词回潮

**这不是配置写错，是分段的固有代价。**

## 三、一个反直觉的收获

**v16（分段 + 数据改动）= 7 项，比 v17（分段 + 原数据）= 9 项更好。**

说明 **v16 的数据改动本身是有效的**，它的正面作用**部分抵消**了分段的伤害。
所以下一步应该是：**保留 v16 的数据，去掉分段**。

## 四、意外发现：机器夜间会进入低功耗状态

v17 四段的步时差异极大：

| 段 | 步数区间 | 步时 |
|---|---|---|
| 1 | 1–80 | **31 秒** |
| **2** | 81–160 | **240~340 秒** |
| 3 | 161–240 | **28 秒** |
| 4 | 241–292 | **27 秒** |

**第 2 段正好落在机器长时间空闲的时段，第 3、4 段机器恢复使用后步时随即回落。** 这说明除了「进程内显存碎片」，
还有第二种限速机制：**机器空闲/合盖时进入低功耗状态被降速**。

两者都真实存在（有一次就是在我自己正用电脑时把 195 秒拉回 28 秒的，碎片那条也成立）。

## 五、下一步（修正后的方案）

| 优先 | 动作 | 理由 |
|---|---|---|
| **P0** | **v18 = v16 的数据 + 单段长训练**（不用分段） | v16 数据有效（抵消了分段的伤害），去掉分段即可两全 |
| **P0** | **训练期间禁止机器休眠/合盖** | 消除夜间低功耗限速（v17 第 2 段的 6 小时就是这么来的） |
| **P1** | 若必须要分段，则用 `lr_scheduler_type: constant` + 更低学习率 | 没有余弦曲线就没有"重启即最高 LR"的问题（未验证） |
| **P1** | 或升级 torch ≥2.6 | 从根上解除 CVE 限制，续训可保留 scheduler.pt（有搞坏环境风险，待我定） |
| **P2** | 声线问题 | 保护多人对白样本没起效 → 原因不在数据，可能在指令或容量 |

## 六、方法论收获

**这是"一次只改一个变量"这条纪律的第一次严格执行，直接拿到了干净结论。**

此前三次违反它，代价是三个说不清的结论：
1. "训练量 > 配比"（v6→v8 同时加多要点 + 加量）
2. "夜间不降频"（被 v12 反例推翻）
3. v16（同时改数据 + 分段，无法归因）

**单变量实验虽然要多花一次训练的时间，但比连着三次瞎猜便宜得多。**
