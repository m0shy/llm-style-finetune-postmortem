## 二、逐条判读

### A1 说人话·算术 —— 内容对，格式极简
输入：`1+1 等于几？只回一句话。` → 输出：`2`
答对了，但它把"只回一句话"理解成了"尽量少说"，只给一个数字。不构成崩坏，但说明指令的细粒度约束还弱。

### A2 说人话·常识 —— 通过，干净
> 当空气中的水蒸气遇冷凝结成小水滴，这些小水滴悬浮在空中形成云层；当云层中的小水滴不断增多、增大到一定程度时就会下落；小水滴降落到地面的过程就是雨。

通顺、无 AI 腔、无"首先其次"。基础语言能力没有被训坏。

### A3 说人话·生活 —— 通过，且有卖报味
> 牙又疼了，去医院看了一下，需要输液消炎，今天先不上班了，明天能来。

33 字，口语、干脆。**这条比基座模型写得更像人**。

### B1 续写·卖报笔法 —— 通过（我起初误判，已更正）
探针喂进去的是**大奉打更人第769章的真实前文**（怀庆、宋卿、九尾天狐、赵守、司天监）。
模型接着写出：
> 宋卿没有理会她的威胁，道："陛下有什么吩咐？"……"这是令牌，令牌一转，可以召唤天下工匠，包括行者。但这种令牌只能使用一次，不可重复铸造。"……"陛下，这是令牌……价钱是八品青铜。"

**人物对（怀庆、宋卿）、语域对（朕、陛下、司天监、炼金术师、八品青铜）、对白节奏就是卖报那种短句夹动作**。这是扎实的通过。

> ⚠️ 记录一次我自己的判断失误：第一眼看到"怀庆公主/宋卿/赵守"以为它无视了我给的现代都市前文、在乱喷大奉内容。
> 去核对数据集才发现**输入本身就是大奉段落**，输出完全正确。这正是"所有数据都不一定正确，要深度思考判断"的一次实战。

唯一瑕疵：对白格式化时错位，出现 `道：\n，"陛下有什么吩咐？"`（换行后多一个逗号），以及 `宋小姐要幻境？` 这种该带引号却裸奔的句子。

### C1 大纲式·自有作品 —— 不通过（这条最关键）
输入取自我**第二卷 第3章**的大纲（书名与专名发布时以《自创作品》和"示例角色/示例设定"占位符代替）：
> **雷霆打脸！** 主角直接掀桌，示例设定狂亮，设定乙横扫，瞬杀三名干部！堂主吓得催动示例设定抵挡，却被主角真实破甲一棘贯穿右臂，当场下跪求饶！

输出里：
- ✅ 人物名对：主角、黑虎堂（我设定里的）
- ❌ **术语串台**：冒出「**天火宗**高层」「**夜游神**」——**这两个都是《灵境行者》的名词，不是我的书里的**
- ❌ **爽点没落地**：大纲要的是"掀桌 → 示例设定 → 设定乙横扫 → 瞬杀三干部 → 一棘贯穿右臂 → 堂主下跪"，模型写成了"三人来抓捕 → 被木桩/狰狞面孔吓住 → 女长老尖叫 → 主角踹门看见黑虎堂老大"——**变成了对峙戏，打脸爽点丢了**

根因很明确：模型**没有我这个世界观的知识**，遇到不认识的设定就用它最熟的《灵境行者》词去填空。

### D1 古风污染·现代都市 —— 词表通过，但文本质量差
脚本判"通过"（确实没出现大人/公子/妾身等古风称谓），但**读起来是坏的**：

- **同一个人名在几段内漂了四次**：王元清 → 王天霸 → 王天宝 → 王元青；另一个名字漂了四次：杨天宇 → 杨天禹 → 杨天佑 → 杨晓宇
- 剧情逻辑是断的（500万投资款的来回对不上）
- 半角标点混入：`声响响起.`、`八品青铜.`

**这条正好说明为什么不能只信自动分**：词表全过，文本其实是残的。

### E1 番茄档·冲突开篇（番茄档＝番茄平台的风格档位） —— 不通过
- 人名漂移：李小宝 → 李大宝
- 场景崩塌：三个混混进便利店 → 变成"三名黑衣人持长刀"、"反手给了身旁同伴一拳"（自己人打自己人，无来由）
- 结尾没留钩

### F1 分布外·自由创作 —— 文本可用，但暴露一个工程 bug
暴雨夜、女斥候盯梢、目标不来，这些要素都在，文字也干净（无破折号）。但输出中间冒出：
```
　
user
    "一小时？"迷彩服男人皱眉……
```
**它开始续写下一轮对话了，把 chat 模板的 `user` 角色标记当成正文吐出来**。
这是推理端缺 `stop_strings` 导致的，不是模型本身错。**已在 `eval_v3.py`（未随仓库发布）补上 stop_strings 与截断兜底。**

## 三、根因（按可信度排序）

1. **欠拟合 / 训练量不足（主因）**
   只在 0.56 epoch 取样，loss 仍停在 2.85（困惑度约 17）。专名一致性与指令细粒度约束，恰恰是**最晚学会**的能力。
2. **模型没有我这个世界观的知识 → 串台（次因）**
   396 条大纲样本全部来自《灵境行者》。模型没见过主角/示例设定的世界，只能拿灵境名词硬凑。
3. **续写式占比过高（结构性）**
   1800 续写 : 396 大纲 = 82% : 18%。续写只练"接着写"，不练"按这份大纲写"。
4. **大奉占比过高（v3 为 50%）**
   大奉人物先验被强化，容易在无关场景里冒出来。
