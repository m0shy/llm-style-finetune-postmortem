# v14b 验收结论：符号问题清零，但抓到了「AI 腔」的真身（卖报＝网文作者"卖报小郎君"的简称）

> 训练：2632 条（去掉通用回放 + SYS_RULES 加【禁网络符号】），rank 8，1.0 轮
> 结果：**exit 0，用时 2 小时 29 分，28 秒/步**（白天跑的，再次证明跟"夜间"无关）
> eval_loss：2.8892(50) → … → 2.801(300)

---

## 一、✅ 确定修好的：异常符号清零

| | 异常符号混入 | 拉丁字母混入 |
|---|---|---|
| v13 | **2 / 16** | 1 |
| **v14b** | **0 / 16** | **0** |

内容上，v13 曾出现 `(╯°□°）╯︵ ┻━┻`（掀桌颜文字）、`♂♂♂♂♀♀♀♀`、`你TM怎么是这样？`。

**去掉通用回放 + 加禁符号条款，这个问题彻底清零。** 这是本轮最硬的结论。

其余：十探针（固定的对照测试输入）全部通过、**破折号 0**、原文复读 0、句长波动首次进入卖报区间（16.6）。

## 二、🔴 最重要的一步：验证「AI 腔」到底是真的还是测假

我评 v14b 时，风格距离显示"AI 腔三项变重"（比喻 1.92→2.85、套话 1.35→1.93、直陈 1.46→1.63）。
但我意识到这**可能是测量混杂**：我的探针全是高戏剧强度场景（掀桌/诀别/感情戏），
而基准线是原著**全部章节**的平均 —— 高戏剧场景天然比喻和情绪更多。

**于是做了个干净验证**：拿 B1（续写）那一场戏，**同一位置**比「作者本人怎么写」vs「模型怎么写」。

| 指标 | **卖报本人** | **模型** |
|---|---|---|
| **直陈情绪 /千字** | **0.0** | **1.99** |
| **比喻词 /千字** | **0.0** | **3.98** |
| 套话连接词 | 0.0 | 0.0 |
| 升华句 | 0.0 | 0.0 |
| 平均句长 | 23.5 | 26.9 |
| 句长波动 | 16.2 | 14.8 |

**卖报本人写这场戏：零比喻、零直陈情绪**，全靠动作和对白推进：

> 怀庆淡淡道："打开密室大门，朕要见魏公。"
> 宋卿当即取来一大串钥匙，逐一打开那扇让四品武夫都束手无策，但墙壁一拳就能打穿，所以然并卵的铁门。
> "退下吧！"怀庆吩咐道。宋卿欢快的回去做实验。

模型则写"他身材魁梧，五官俊朗……看上去像是刚从朝会上下来的官员"（比喻 + 外貌铺陈）、
"小心翼翼问道"（直陈情绪）。

### 结论

**「AI 腔」是真的，而且诊断更精确了：模型在往卖报的稿子里加卖报自己不加的东西。**

同时这个验证**反过来证明了我的风格距离工具是有效的** —— 它在同一场景上抓出了真实差异，
不是长度假象、也不是场景强度造成的假象。

## 三、不算数的（样本太少，不下结论）

| 项 | 数值 | 为什么不下结论 |
|---|---|---|
| 要点覆盖率 | **2.3/6**（n=3）vs v13 的 3.4/6（n=5） | 样本数不同，且单次波动 0~5/6（有一次 0/6 全丢），方差远大于差异 |
| 声线（仅 C1） | 2 个角色有台词、主核对白占比 | 对白数太少（4 句 / 3 句） |
| eval_loss | 2.801 vs v13 的 2.7169 | 高一些，但 loss 与生成质量的对应关系本届已证不成立 |

## 四、本轮又遇到一次 GPU 崩溃

测要点覆盖率时崩过一次：`RuntimeError: CUDA error: an illegal memory access`
（bitsandbytes 的 4bit 算子，与 v8 那次同一个错）。**降 n=5→3 重跑后通过。**

这说明这台机器的 GPU 不稳是**长期的**，不是单次事故：
- v8 训练崩（同错）
- TDR 事件多次（见 `ops/tdr-gpu-timeout.md`）
- **v14 整机意外关机**
- 本次测量又崩

**这是硬件层面的可靠性问题，不是配置能彻底解决的。** 应对方式：多检查点（save_steps 50）、
看门狗自动续训、测量任务降采样。

## 五、下一轮该做什么（针对 AI 腔）

既然诊断精确了，修法也应该精确：

| 优先 | 动作 | 理由 |
|---|---|---|
| **P0** | **数据侧对抗**：从源书里挑出"零比喻、零直陈情绪"的段落，**提高它们的采样权重** | 模型加比喻是因为它没见过足够多的"不加比喻照样好看"的写法 |
| **P0** | 指令侧改写【禁网络符号】条款，**不再逐个列举那些符号** | 现在写着「如 ┻ ╯ ♂ ♀ ° 之类」，有负向提示的嫌疑（虽然符号确实没了） |
| **P1** | 在 SYS_RULES 里加一条正向约束：「情绪靠动作与对白承载，不直说；少用比喻」 | 直接针对验证出来的差异 |
| **P1** | 用上面那个「同场景 vs 原文」的对比法，做成常态化验收 | 它比"vs 全书平均"更干净，应该加进工具 |
| **P2** | rank 加倍 | 必须先压短 prompt 把显存降下来，否则会重演 v14 的整机崩溃 |
