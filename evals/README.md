# evals · 版本验收记录导读

按 00 → 11 顺序即模型的完整迭代史（v1 → v18），每篇记录一轮训练的验收结论与教训：

| # | 文档 | 一句话导读 |
|---|---|---|
| 00 | `00-v1-first-finetune.md` | v1 首次微调验证：复读塌缩解决、语言恢复通顺，但内容忠实度差（只用了片段级数据）。 |
| 01 | `01-v3-human-judgement.md` | v3 真人逐条判读：说人话与卖报笔法成立，仍带术语串台、专名漂移、爽点不落地三大硬伤。 |
| 02 | `02-v5-regression-and-v6-fix.md` | v5 → v6 同口径对比：训得更多反而退步，根因是训练 prompt 未与推理端逐字对齐。 |
| 03 | `03-v6-pollution-fixed.md` | v6：专名块注入修好串台与人名漂移，但带出破折号与设定细节错误；含两轮补测与根因自查。 |
| 04 | `04-v8-corrected-uplift.md` | v8 更正版结论：n=1 采样导致误判，5 次采样重测证实多要点样本有效（要点覆盖率 +73%）。 |
| 05 | `05-v11c-confounded-variables.md` | v11c：变量混杂实验——训练量的影响大于数据配比，单调配比得不出干净结论。 |
| 06 | `06-v13-most-balanced.md` | v13：历代最均衡的一版（节奏类指标首次进区间），但通用回放带出异常符号回归；附长训稳定性运维发现。 |
| 07 | `07-v14b-symbols-zero-ai-tone.md` | v14b：异常符号清零；用同场景对比确诊「AI 腔」是真的——模型在加作者自己不加的东西。 |
| 08 | `08-v15-style-win-costs.md` | v15：AI 腔三项全部回到区间，代价是对白占比矫枉过正、声线退步、要点覆盖被过滤器误伤。 |
| 09 | `09-v16-segmented-training.md` | v16：要点覆盖率历代最高，但分段训练拖累风格；附一次「同时改两个变量」的方法论自我批评。 |
| 10 | `10-v17-segmentation-culprit.md` | v17：单变量归因实验——分段训练就是风格退化元凶；顺带查明机器空闲/合盖低功耗是第二种限速机制。 |
| 11 | `11-v18-structural-tradeoff.md` | v18：结构性发现——覆盖率与风格此消彼长，越像卖报越会漏掉大纲第一个要点。 |

另有 `golden-benchmark.md`（与版本无关的通用验收方法基线）与 `evidence/`（各版对照的原始探针输出）。
