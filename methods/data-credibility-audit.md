# 数据可信度审查与假设反省

> 触发：一条我拿来当纪律用的提醒——"所有数据都不一定正确，要辩证看待、深度思考判断"
> 结论：上一轮整理的 2026 网文知识中，**约一半是自媒体话术，不能当事实用**；且我自己的三条项目假设存在实质风险。

---

## 一、可信（多源交叉 + 逻辑自洽）

| 结论 | 依据 | 可信度 |
|---|---|---|
| 黄金三章（前 300 字出冲突、1000 字出爽点） | 3 个独立来源 + 行业多年共识 | 高 |
| 3-5-10 节奏法则 | 2 源结构一致，契合连载算法 | 中高 |
| 毒点清单（注水/降智/圣母/逻辑崩坏） | 4+ 源重叠，读者长期吐槽主题 | 高 |
| 起点重质感 vs 番茄重节奏 | 与"付费 vs 广告"商业模式自洽 | 高 |
| 番茄限制纯 AI 生成 | 与近几年平台治理方向一致 | 中高（**条款细节待核实**） |

## 二、存疑（精确百分比 + 无出处 = 内容农场特征）

**以下数字不得作为事实引用，仅可作方向参考**：
- 「追读率高出 47%、完读率提升 32%」
- 「金句钩子使下一章打开率提升 50%+」
- 「框架创作完稿率高 4 倍、签约率提升 62%、阅读时长增加 58%」
- 「全网阅读量同比暴涨 300%」「无 CP 女频新增在读暴涨 320%」
- 「番茄签约机会仅 3 次，卡在 2 万/5 万/8 万字」

**并判定**：所检索到的「三平台加权 TOP10 榜单」为内容农场产物——其自造指标「核心数据加权分 9.8」无任何定义，且同一作品在不同文章中作者署名不一致（一处"未知"，一处"杀虫队队员"）。**不采信为市场实况。**

## 三、矛盾点（最有价值的一处）

资料 A 称「番茄严禁**灵异**」；资料 B 称「中式民俗怪谈是**增速第一**黄金赛道」。

**深挖后的推断**：尺度落在**归因方式**上——
- 把异常归因给"鬼神" → 违规
- 把异常归因给"规则 / 系统 / 组织 / 能量" → 可通过

**对我这本书（《自创作品》为发布代称）的含义**：
- 天然护身符：**「自创作品」框架本身就是"系统归因"**，这是安全外壳
- 风险点：**「示例设定」（打码占位的功法/副本名）、「禁断图书馆」等副本若被写成真鬼神显灵**，则触碰红线
- **执行**：生成约束里明确「异常必须可归因于游戏机制/组织/能量规则，不得写成鬼神显灵」

## 四、样本偏差（系统性）

检索到的 5 条全为自媒体（今日头条系 + NGA）。其激励是点击率而非准确性，系统性偏好：
- 秘籍体（N 大法则 / 爆款密码）
- 绝对化（"百分百拒稿""永久封禁"）
- 可截图金句

→ 它们反映的是**"写手圈流传的说法"，不等于平台真实规则**。平台规则应以官方公告为准；**本项标记为待一手核实**。

## 五、⚠️ 我自己的三条假设，经不起推敲

### 假设 1：「续写式」是最佳主范式 —— **有风险**

- 我一直主推续写式（前文→后文），量级大、可自动化
- **但我的真实使用场景是"给大纲、无前文"**
- 续写式教的是「依赖前文往下滑」；我要的是「凭大纲从零起笔」——**这是两种能力**
- **风险**：模型可能变成"离开前文就不会写"，给大纲反而卡壳
- **修正**：大纲式样本必须保持更高占比（当前 396/2196=18% 偏低）；这正是追加「终点提示续写」范式的原因——它更接近真实输入形态

### 假设 2：大奉打更人占 50% —— **可能污染语言底色**

- 同一作者，但《大奉》是**古装**（老爷/大人/打更人/钦天监），《灵境》是**都市**
- 作者的技术（节奏/钩子/幽默）可跨界；**词汇底色不可**
- **风险**：900 条古风样本可能让模型在现代场景里冒出「老爷」「在下」等古装词
- **修正**：v3 完成后**立刻做古风词污染测试**（用现代场景提问，检测古装词汇泄漏率）。若污染明显 → v4 将大奉降到 300–400 条，或只取其**对话/节奏段**、剔除古风名词密集段

### 假设 3：默认按番茄规则 —— **越位了**

- "开篇即高能 / 3 章必爽 / 无铺垫" **只对番茄成立**
- 起点允许慢热，甚至**拒收空洞爽感**
- **在目标平台确认之前，把番茄规则当默认是越位的**——若我瞄的是起点，这套建议会帮倒忙
- **修正**：先确认目标平台；在约束中做成**可切换的"平台档位"**

## 七、一句话总结

**上一轮那份清单，方向大体可用，但数字全是话术，榜单是编的，还漏了一个真矛盾（灵异 vs 民俗怪谈）；而我自己的三条设计假设里，有一条（续写范式）是方向性风险，有一条（大奉占比）是明确隐患。**
