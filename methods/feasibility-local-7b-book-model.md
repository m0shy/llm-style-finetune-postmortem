# 本地 7B 专书写作模型：可行性拆解与路线

> 目标（我当时的原话）：不求高深智慧，只要它拥有**那一本书的语言逻辑、结构和艺术**；用于长期创作，追求本地、免费、可服从。
> 结论：**可行，但"艺术"必须拆成三件事**——语言逻辑（可学）、结构（要换数据形态）、判断层艺术（学不到，靠外挂）。

---

## 一、把目标拆成三层，逐层判可行性

| 层 | 具体指什么 | 可学性 | 需要的数据形态 |
|---|---|---|---|
| **L1 语言逻辑** | 高频词/称呼/口头禅、句长分布、断句习惯、长短句韵律、段落密度、吐槽腔与冷幽默 | ✅ **完全可学**，100–300 条就能出效果 | 片段级即可（现有数据够） |
| **L2 结构** | 场景内部组织（起→承→转→收）、对话与动作的交替节奏、铺垫→爆发→余韵、场景时长控制 | ⚠️ **可学，但现有数据学不会** | 必须是**完整单元**（场景级/章节级），不能是中段碎片 |
| **L3 判断层艺术** | 哪里该留白、哪个细节值得写、怎样写才"意难平"、节奏何时该停 | ❌ **学不到**（这是取舍判断，不是统计规律） | 无解 —— 必须**外挂到大纲** |

### 关键洞察
> **模型学不会"哪里该留白"，但它能学会"留白长什么样"。**
> 所以：**判断留给我（大纲），落笔交给模型。** 这恰好契合我本来就要写大纲这件事。

---

## 二、L2 为什么现在学不到——这是数据形态问题，不是模型智商问题

- 现在 240 条的 `output` 全是**章节中段**：没有开端、没有收束、事件弧断裂。
- 模型看到的序列永远是"从中间开始、到中间结束"→ 它只学会"无限延伸"，学不会"收束"。
- **7B 的智力足够**处理场景级结构（32K 上下文绰绰有余）；缺的是**完整单元的示范**。

**结论**：想学结构，不用换更大的模型，**要换样本形态**。

---

## 三、数据从哪来——我手上就有 800 万字

《灵境行者》约 1020 章 / 800 万字，这是**现成的富矿**，缺的只是"标注"。可切出的规模：

| 形态 | 切法 | 可产条数 | 目标规模 |
|---|---|---|---|
| 片段级（现有） | 按引擎分段 | 3000–6000 | L1 用 500–1500 即可 |
| **场景级**（推荐） | 按场景边界切，每段必有起→收 | 1500–3000 | 目标 1500–3000 |
| 章节级 | 每章 1 条（整章大纲 → 整章正文） | ~1020 | 目标 500–1500 |

> 起点就是我现在这套引擎 + 流水线，**不需要外部数据**。

---

## 四、经济账：一次性标注成本，换长期本地免费

| 项 | 强模型 + skill（现状） | 本地 7B 微调 |
|---|---|---|
| 每次生成成本 | 高（长文本、反复重试） | **0**（本地） |
| 服从性 | 差（强模型"自作主张"违反 skill） | **高**（微调把风格写进权重） |
| 边际成本 | 随字数线性上升 | 几乎为零（批量跑） |
| 一次性投入 | 无 | **大纲标注**（用中转 API 跑一次，把原文反推为大纲） |
| 长期账 | 越写越贵 | 写多少都不加钱 |

**事后验证，这个判断是对的**：微调的真正价值不是"更聪明"，而是**「服从性」+「零边际成本」**。

---

## 五、路线（三档，按目标选）

### 档 1｜只要 L1（语言逻辑/腔调）— 本周可完成
- 数据：现有片段级扩到 **500–800 条**
- 动作：`input 骨架化` + `v3 硬约束指令` + `v2 超参` + `通用语料 replay` + `解码重复惩罚`
- 产出：给 200 字大纲 → **800 字腔调高度一致的片段**；细节密度中等，需人工润色
- 验收：**风格盲测**（10 段让人分辨是模型还是原文，正确率 ≤40%）

### 档 2｜要 L1+L2（场景结构）— 推荐，2–4 周
- 数据：**场景级**完整单元 **1500–3000 条**（每条含完整起承转合）
- 产出：给场景大纲 → **1500–2500 字的完整场景**，内部有起伏、能收得住
- 验收：随机 20 个场景大纲 → 无逻辑断裂、有收束、细节密度达标（可脚本量化）
- **这是"够用"的档位**——配合编排层即可产出整章

### 档 3｜要 L3 的"结构"（章节）— 高成本
- 数据：**章节级** 500–1500 章
- 产出：给章节大纲 → 整章（3000–4000 字）
- 风险：整章生成的一致性（人名/道具/伏笔）仍需外挂状态管理

---

## 六、无论哪档，这 6 件事都必须做（否则白训）

1. **样本必须是完整单元**（有头有尾），不是中段碎片 —— 学结构的前提
2. **input 必须骨架化**（只给动机+动作+转折，抽掉名词与画面）—— 否则学不会扩写
3. **指令多样化 + 硬约束**（10 变体 × 逐条落实/不得增删/禁解剖心理/细节自生）
4. **超参收敛**（rank 8 / 去 all / epoch 2 / lr 5e-5 / dropout 0.1 / 早停）
5. **混 5–10% 通用语料 replay** —— 防基座语言能力被覆盖
6. **解码带重复惩罚**（rep 1.15–1.3 / no_repeat_ngram 4 / temp 0.8）

---

## 七、最终形态（推荐架构）

```
我写：全书大纲 → 章节大纲 → 场景大纲（含"哪里留白"的判断）
       ↓
模型做：场景大纲 → 1500–2500 字场景正文（腔调一致、有结构）
       ↓
编排层：拼接场景 → 跨章一致性检查（人名/道具/伏笔账本）→ 成章
       ↓
我做：终审 + 补判断层艺术
```

**分工**：判断归我，落笔归它，长线归脚本。这样 7B 的"智力天花板"就不再是瓶颈。

---

## 八、诚实的天花板

- ✅ 能得到：**高度一致的专书腔调 + 合格的场景结构**
- ⚠️ 需要人工：终审、跨章一致性、判断层的取舍
- ❌ 得不到："自己构思出好情节"——但那本来就不是我要的

**一句话**：我要的不是"会写作的 AI"，是"**听我指挥的笔**"。这个目标，可行。
