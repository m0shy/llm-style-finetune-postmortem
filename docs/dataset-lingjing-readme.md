### 两套 Instruction 模板

**主模板（74 条）**：

> 请根据以下剧情大纲，撰写一段小说正文。要求：极具画面感与节奏感，多用短句，注重感官描写（视觉/听觉/触觉），禁止使用'首先/其次/总之'等公文连接词，通过具体的动作和微表情展现人物心理，严禁直接陈述情绪。

**规则发现模板（方案3，8 条）**：

> 请根据以下核心规则/线索，描写角色在紧张处境中发现并理解它们的过程。要求：严禁直接罗列设定或像说明书一样陈述。必须通过角色的具体动作、感官体验（如看到某物时的生理反应）、心理活动以及与环境的互动，将这些规则自然地'展示'出来（Show, don't tell）。

## 四·补 · 常设规范

1. **单批次按【段数】控制**：切分后预估入选量超过 **25 条**，必须主动拆分批次。
2. **语料过滤四层**：整段排除 → 尾部批注（含成绩经营类补强词）→ 口语变体（请个假/明天补）→ 段尾符号归一化；**必须先修剪尾部再判断整段**。词表规则见第一节折叠区。
3. **每次改写 Input 的表达形式（叙事↔清单）后，必须重跑反向核对**。
4. **定校验词前必须先回原文 grep 一遍，禁止凭印象写概括词（5b 起为强制前置步骤）；词表照抄原文实际用词，不做同义替换。**
5. **候选段（BORDERLINE）默认永久搁置；如需复评入集，须单独报备并重跑双向核对。**
6. **校验词核对前置到写大纲阶段**（5c 起为强制前置步骤，5c 已验证零误报）：写完 `checks` 先跑脚本回原文核验，全部命中才进组装。

## 七、质量红线

1. **`output` 不变量（2026-09-11 裁决B 修订）**：`output` ＝ **引擎四层处理后的段文本逐字复制**；层4「段尾符号归一化」剪除段尾独立「……」**不计为原文丢失**。组装时由脚本回填并自检（当前 **115/115** 通过）。
2. `input` 必须与 `output` 信息等价：正向逐点可查、反向转折不漏。
3. 不确切的判断标注 `[UNCERTAIN]`。
4. **同源探针 / 切分覆盖率**：首批、范式变更、引擎改动时必跑；**常规批次跑逐字命中 + Input 双向核对**。
5. **定校验词前必须先回原文 grep 一遍，禁止凭印象写概括词（5b 起为强制前置步骤）**；词表照抄原文实际用词（用关键词组匹配，不用整句字面匹配），不做同义替换。
6. **系统面板使用边界**：允许以系统面板作为**场景引入**（**≤5 行**，其后主体必须是叙述 / 对话 / 动作）；**禁止纯面板段入选**（整段皆为面板字段罗列、无角色行动线）。
   > 依据：批次4 `SEG-0246-05` 以 5 行面板开头、主体为叙述，判**保留**。

## 八、历史记录（v1/v2 降级范式，已废弃）

早期把 `instruction` 写成"请将以下充满AI味…重写…"、`input` 写成"降级后的AI味文本"，用 R1–R7 规则加 Plan B 对抗性错位短句做降级，目的是训练"去 AI 味改写"。该范式会让模型学成润色工具，**已被 v3 创作范式整体取代**。相关记录见返工报告_PlanB（未随仓库发布）。

## 九、LLaMA-Factory 接入

`dataset_info.json` 当前注册了**三个键**：

| 键名 | 角色 | 说明 |
|---|---|---|
| `lingjing_creator` | **主键（训练时必须选这个）** | v3 直接创作者范式命名，与当前 `input = 剧情大纲 / output = 原文正文` 规格匹配 |
| `lingjing_deai` | 别名（旧范式遗留） | v1/v2「去 AI 味」范式沿用下来的名字，仅作兼容；`file_name` 与字段指向同主键完全一致 |
| `lingjing_final` | 最终交付键 | 240 条最终交付集 `dataset_lingjing_final.jsonl`（能力预估用，见 `data-production/capability-estimate.md`） |

把 `dataset_lingjing.jsonl` 与 `dataset_info.json` 拷入 LLaMA-Factory 的 `data/` 目录即可在训练配置里直接选用。

> ⚠️ **训练时必须选 `lingjing_creator`**。前两个键读的是同一份数据，但用旧名 `lingjing_deai` 容易让人误以为在跑已废弃的旧范式。
> 若训练配置里仍引用 `lingjing_deai`，请改用 `lingjing_creator`；确认无引用后可删除别名键。
